Procurando a extensão Despachantes Consultas neste navegador…

🧩 Instale a extensão para agendar por esta página

Agenda Transferência de Propriedade, Transferência de Jurisdição e Troca de Município no site do Detran RJ. Você só marca o "Não sou um robô"; a extensão escolhe a cidade, o posto, o primeiro dia e horário livres e, sem vaga, tenta de novo sozinha.

Quem abre o site do Detran e preenche é a extensão, no seu Chrome. Ela é grátis, não precisa de cadastro e os veículos ficam só no seu navegador: não vão para o nosso servidor.

Funciona no Google Chrome (ou no Microsoft Edge) no computador. Abra esta página por ele: www.despachantesconsultas.com.br/extensao-chrome

1. Baixar a extensão (versão com o agendamento)

  1. Baixe o arquivo e descompacte (botão direito → Extrair tudo).
  2. No Chrome, abra chrome://extensions e ligue o Modo do desenvolvedor (canto de cima, à direita).
  3. Clique em Carregar sem compactação e escolha a pasta descompactada.
  4. Volte para esta página e recarregue (F5).
⬇️ Baixar extensão (.zip)
Aviso de "modo do desenvolvedor"? O Chrome mostra essa mensagem para toda extensão instalada fora da loja. É uma mensagem padrão; não quer dizer que a extensão é perigosa.

2. Pela Chrome Web Store

Instalação com um clique. A versão com o agendamento ainda está em análise na loja: se depois de instalar esta página continuar pedindo a extensão, use a opção 1.

Abrir na Chrome Web Store ↗
⚠️ Marque o "Não sou um robô" na aba do Detran que a extensão abriu.

Veículos

Tudo fica salvo neste Chrome, enquanto você digita. Testar abre o site do Detran e só preenche o formulário, sem enviar. Agendar para no captcha: marque-o na aba do Detran e o resto é automático (cidade, posto, primeiro dia e horário livres). Sem vaga, a extensão tenta de novo sozinha no intervalo escolhido.

Opções

Os dados dos veículos ficam só neste navegador (na extensão) e só vão para o site do Detran, no momento do agendamento. Nada é enviado para a Despachantes Consultas.
