Agendamento Detran RJ em três opções: programa para Windows, versão Java ou extensão do Chrome. Gratuito.

💻

Opção 1: Agendamento Detran RJ para Windows (instalador)

Instalador .exe · 3 MB · Windows 10 e 11

Agenda no site do Detran RJ: Transferência de Propriedade, Transferência de Jurisdição, Troca de Município, 1ª Licença, Alteração de Características, 2ª Via de CRV, Retificação de Dados e ATPV-e / Intenção de Venda. O DUDA e a data da venda você informa já na tela do programa, quando o serviço pede. Você só marca o "Não sou um robô"; o programa escolhe o posto, o dia e o horário e tenta de novo até achar vaga.

  • ✓ Instala o Node.js se o computador não tiver (opção já marcada no instalador)
  • ✓ Inicia sozinho com o Windows, com um ícone perto do relógio (dá para desligar)
  • ✓ Precisa do Google Chrome instalado
  • ✓ Os dados dos veículos ficam só no seu computador
Aviso "O Windows protegeu o computador"? É a mensagem padrão do Windows para programas novos, que ainda não têm assinatura digital comprada. Não quer dizer que o arquivo é perigoso. Clique em Mais informações e depois em Executar assim mesmo.
⬇️ Baixar para Windows (.exe)
☕

Opção 2: versão Java (sem instalador)

Arquivo .zip · 15 MB · Windows 10 e 11 · o Java já vem junto

O mesmo agendamento, com a mesma tela, em outro formato: não tem instalador .exe. Use esta opção se o Windows bloquear o instalador acima ou se o computador não deixar instalar programas.

  • ✓ O Java vem dentro do pacote: não precisa instalar nada (é o Java da Microsoft, com assinatura digital)
  • ✓ Descompacte a pasta (botão direito → Extrair tudo) e dê dois cliques em Abrir Agendamento Detran
  • ✓ Precisa do Google Chrome (ou do Edge, que já vem no Windows)
  • ✓ Os dados dos veículos ficam só no seu computador; para atualizar, baixe e descompacte por cima
⬇️ Baixar versão Java (.zip)
🧩

Opção 3: extensão do Google Chrome

Versão 1.3.0 · arquivo .zip · qualquer computador com Chrome

O agendamento roda dentro do seu próprio Chrome, sem programa para instalar no Windows. A tela é a página despachantesconsultas.com.br/extensao-chrome, com os mesmos serviços das outras opções. A extensão também mostra o seu saldo e abre o painel.

  1. Baixe o .zip e descompacte (botão direito → Extrair tudo).
  2. No Chrome, abra chrome://extensions e ligue o Modo do desenvolvedor (canto de cima, à direita).
  3. Clique em Carregar sem compactação e escolha a pasta descompactada. Já tinha a versão antiga? Remova-a antes (os veículos salvos continuam).
⬇️ Baixar extensão (.zip) Ver na Chrome Web Store ↗

No celular: abra o site no navegador e use Adicionar à tela inicial (no iPhone, pelo Safari em Compartilhar) para ter um atalho como um app.
