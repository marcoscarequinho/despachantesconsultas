Integração API

        
Endpoints do catálogo "Acesse Aqui Para as Principais Consultas" para integrar via API. Requer uma chave de API (peça ao suporte) — cada chamada é cobrada do saldo da conta vinculada à chave, no mesmo valor da consulta no painel.

      


      

        💡
        

          Envie a chave no header X-API-Key (ou Authorization: Bearer).
          Apenas os serviços de conferência manual (upload de PDF pela equipe) não estão disponíveis por essa API.
        

      


      

        

          
          
        


        

      


      

        
Códigos de Status

        

          

            200
            

              
Sucesso

              
Retorna PDF em base64 e/ou URL do PDF.

            

          

          

            400
            

              
Dados inválidos

              
Placa, renavam, cpf/cnpj ausente ou inválido.

            

          

          

            401
            

              
Não autorizado

              
Chave API inválida, inativa ou não fornecida.

            

          

          

            402
            

              
Saldo insuficiente

              
Sua conta não tem saldo suficiente para esta consulta. Adicione saldo e tente novamente.

            

          

          

            403
            

              
Acesso negado

              
Chave ativa mas usuário sem permissão.

            

          

          

            404
            

              
Não encontrado

              
Endpoint não encontrado.

            

          

          

            429
            

              
Rate limit

              
Rate limit excedido.

            

          

          

            500
            

              
Erro interno
